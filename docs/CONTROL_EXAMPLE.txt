ОГРАНИЧЕНИЯ И НЕВЫПОЛНЕННЫЕ ПРОВЕРКИ
Результат — предварительный подбор площади и рукавов, не полный проект фильтра.
Не проверены: сопротивление, скорость между рукавами, эффективность улавливания, стойкость ткани и точка росы.
Секции равные; используется только рабочая боковая поверхность цилиндрических рукавов.
Пересчёт расхода: идеальный газ (Z=1), абсолютное давление; сухой→влажный по объёмной доле водяного пара без изменения сухого состава.
Дополнительный поток учитывается только если он проходит через работающую ткань в рассматриваемом режиме; не суммируйте один поток дважды.
