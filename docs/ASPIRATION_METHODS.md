# ТехМИ Аспирация 2.2: модели, источники и проверка

## Границы версии

Расширена настольная программа `filter_v2.py`. Существующие функции
`calculate` и `report_text`, коэффициенты БНТУ, `calculator.py`,
`desktop.py` и веб-API не менялись. Новые модели — `aspiration.py`,
интерфейс — `aspiration_ui.py`. Версия 2.2 продолжает существующую ветку v2.
Веб-версия пока содержит только прежний расчёт. Новые расчёты не используют
скрытого переноса исходных данных между вкладками.

Порядок вкладок: Фильтр, Альтернатива, Отчёт фильтра, Воздуховод,
Вентилятор, Пыль, Литература. Список над вкладками открывает любой раздел,
даже если названия вкладок не помещаются. Каждый новый расчёт сохраняет
свои входы при переключении; изменение входа аннулирует прежний отчёт.
Новые отчёты — TXT UTF-8 с BOM для Windows.

## Реестр покрытия и размерности

Все Q — рабочие м³/ч; для SI используется Qs = Q/3600, м³/с.
Нормальные расходы предварительно переводят в рабочие в прежнем расчёте.
Объёмная основа, состав и влажность должны соответствовать сравниваемому режиму.

| Расчёт | Цепочка | Статус и границы |
|---|---|---|
| По скорости фильтрации | Fnet = Qs/v; q = 60v | Реализовано; v задаётся с основанием, м/с |
| По аналогу | v = Qref/(3600Fref,net), затем та же цепочка | Реализовано; перенос нагрузки, не независимый закон для новой пыли |
| Секции и запас | Fgross = Fnet(1+s/100)n/(n−k) | n,k целые; 0 ≤ k < n, одинаковые секции |
| Рукава | A1=πDL; b=ceil(Fgross/(nA1)); N=nb | D в м, L — активная длина; торцы исключены |
| Проверка геометрии | Factive=(n−k)bA1; vactual=Qs/Factive | Действующая площадь, а не установленная gross |
| Сравнение | 100(Fgross/Fcomparison−1) | Только площади gross в м²; ввод второго результата явно |
| Диаметр воздуховода | Dtarget=sqrt(4Qs/(πvtarget)) | Теоретический размер, не подбор стандартного диаметра |
| Скорость выбранного сечения | A=πD²/4; v=Qs/A | Диаметр задаётся отдельно, мм→м |
| Сопротивление участка | pd=ρv²/2; Δpf=λ(L/D)pd; Δpl=Σζpd | λ Дарси; все ζ отнесены к скорости этого участка |
| Вентилятор | Δpt=(Δpnetwork+Δpfilter+Δpother)(1+r/100) | Потери одного расчётного пути при одном расходе |
| Мощность | Pgas=QsΔpt; Pshaft=Pgas/ηfan; Pel=Pshaft/ηdrive | Вт→кВт; 0<η≤1; тип давления — полный |
| Пылевой баланс | Min=QC/1000; Mcaught=ηMin; Mout=(1−η)Min | C в г/м³, M в кг/ч, η в долях |
| Концентрация выхода | Cout=1000C(1−η) | мг/м³; одинаковый объёмный расход входа и выхода |

Проверка размерностей: Qs/v → м²; ρv² → кг/(м·с²)=Па;
λL/D и ζ безразмерны; QsΔpt → м³/с·Па=Вт;
Q·C → г/ч, деление на 1000 → кг/ч.

Дарси–Вейсбах применён как модель одного стационарного малосжимаемого
круглого участка с заданным коэффициентом. Поправки на твёрдую фазу,
сжимаемость, транспортную скорость, износ и отложения не реализованы.
Запас давления не является запасом мощности двигателя во всех режимах.
Параллельные ветви не суммируются последовательно; балансировка сети,
автоподбор вентилятора и проверка устойчивости вне объёма.
Пылевой баланс не прогнозирует эффективность, пожаровзрывозащиту и выброс
по нормативам. Эти ограничения показаны в отчётах.

## Контрольные примеры

- Q=6000 м³/ч, v=1/60 м/с → Fnet=100 м². Три секции,
  одна отключена, запас 0% → Fgross=150 м². Рукав D=0,2 м,
  L=2 м → 40 рукавов/секцию, всего 120, установлено 150,7964474 м².
- Аналог Q=7200 м³/ч, Fnet=100 м² → v=0,02 м/с.
  Прямой метод при той же v даёт одинаковый результат.
- D=1 м, Q=9000π м³/ч → v=10 м/с. ρ=1,2, L=10 м,
  λ=0,02, Σζ=2 → pd=60 Па, трение=12 Па,
  местные=120 Па, всего=132 Па. Удвоение Q увеличивает потери в 4 раза.
- Q=3600 м³/ч, Δpt=1000 Па, ηfan=0,5, ηdrive=0,8 →
  полезная мощность 1 кВт, вал 2 кВт, потребляемая 2,5 кВт.
- Q=1000 м³/ч, C=10 г/м³, η=99% → вход 10 кг/ч,
  уловлено 9,9 кг/ч, выход 0,1 кг/ч, концентрация 100 мг/м³.
- Проверяются η=0/100%, нулевые потери участка, исключение нулевых
  знаменателей, NaN/Inf, отрицательных величин и дробного числа секций.
  Для положительных знаменателей нижний программный предел 1e-9,
  это защита чисел, не физическая рекомендация. Верхние пределы ввода
  также программные, не свидетельство применимости модели во всём диапазоне.
