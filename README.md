+# Screw Performance Calculator (Android)
+
+Простое Android-приложение на Kotlin для расчёта производительности шнека.
+
+## Что считает
+- Объёмную производительность: `Qv = π·D²/4 · S · n/60 · φ` (м³/с)
+- Массовую производительность: `Qm = Qv · ρ` (кг/с и кг/ч)
+
+## Параметры
+- `D` — диаметр шнека (м)
+- `S` — шаг витка (м)
+- `n` — скорость вращения (об/мин)
+- `φ` — коэффициент заполнения (0..1)
+- `ρ` — насыпная плотность материала (кг/м³)
